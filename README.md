# UMKM Go Digital

[![CI](https://github.com/0061Febriana/umkm-go-digital/actions/workflows/ci.yml/badge.svg)](https://github.com/0061Febriana/umkm-go-digital/actions/workflows/ci.yml)

Platform edukasi dan pendampingan UMKM untuk bertransformasi ke era digital.

## Fitur Utama
- **Edukasi**: Artikel dan panduan marketplace
- **Kalkulator Harga**: Fitur smart pricing untuk menghitung harga jual yang tepat
- **Database Terpusat**: Menggunakan Supabase untuk penyimpanan data yang aman

## Tech Stack
- **Framework**: [Next.js 16](https://nextjs.org) (React 19)
- **Database**: [Supabase](https://supabase.com/)
- **Bahasa Pemrograman**: TypeScript

## Cara Menjalankan Project

1. Clone repositori ini dan install dependencies:
   ```bash
   npm install
   ```

2. Jalankan server *development*:
   ```bash
   npm run dev
   ```

3. Buka [http://localhost:3000](http://localhost:3000) di browser Anda untuk melihat hasilnya.

## Deployment
Aplikasi ini dapat dengan mudah di-deploy menggunakan platform seperti [Vercel](https://vercel.com).
